# Дизайн-концепция

## Общий стиль

Сайт должен выглядеть строго, спокойно и консервативно.  
Основная задача — доверие, читаемость и ощущение профессионализма.

## Цвета

- Основной тёмно-синий: `#1D3557`
- Акцентный золотой: `#B08D57`
- Основной фон: `#F7F8FA`
- Карточки: `#FFFFFF`
- Основной текст: `#2F3542`
- Границы: `#D8DCE3`

## Типографика

- Основной шрифт: Georgia / Times New Roman
- Заголовки крупные, но без излишней декоративности
- Длинные тексты должны быть хорошо читаемыми

## Принципы

- Без яркой анимации
- Без перегруженных баннеров
- Без агрессивных продающих блоков
- Больше воздуха
- Чёткая навигация
- Удобство для посетителей 40–70 лет
