# Аудит этапа 2

## Что удалось определить

Старый сайт имеет небольшую структуру и хорошо подходит для переноса в статический HTML-сайт.

Основные разделы:
- Главная
- Партнеры / специалисты
- Услуги
- Клиенты
- Отзывы
- Публикации
- Вопрос-Ответ
- Контакты

Также есть отдельные страницы специалистов.

## Что важно

Сайт отвечает нестабильно, поэтому часть информации пока собрана по доступным фрагментам поисковой выдачи и справочников. Перед финальной публикацией нужно:
- открыть старый сайт вручную;
- сохранить изображения;
- проверить полный текст;
- подтвердить контакты у клиента.

## Рекомендация

Не переносить всё сразу в HTML. Сначала утвердить содержимое файла `docs/content.md`, затем переносить разделами:
1. Контакты
2. Специалисты
3. Услуги
4. Главная
5. Остальные разделы
